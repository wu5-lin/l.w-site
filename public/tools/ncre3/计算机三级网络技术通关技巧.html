计算机三级网络技术 · 通关技巧与资源指南

整理自知乎 / CSDN / B站 / 51CTO 等平台的高分经验帖与备考攻略，结合卷面结构：单选 40 分 + 综合题（填空）40 分 + 应用题 20 分，120 分钟，60 分合格。

1通关总策略（过来人共识）

  1. 不用报班。多数经验帖明确：网课就是把真题归类讲考点，买课不如直接刷题。未来教育题库（约 20–68 元）完全够用。
  2. 真题为王，重复率极高。做 4–5 套真题后你会发现「考的知识点一模一样，甚至有相同的题」。真题至少刷 5 套，时间充足建议把题库里的全部套卷刷完。
  3. 综合题是「白送的分」。题型极其固定，记住模板即可，目标拿 30+/40。
  4. 备考周期 2 周–1 个月最佳。战线太长容易忘且疲劳；知识点总量不大，突击性价比最高。
  5. 综合题千万不要空着！配置命令题的答案往往就藏在题目给出的上下文里，根据配置逻辑能猜出大半。

3综合题四大题型解法模板

第 1 题：IP 地址计算（约 10 分，必拿）

给一个 IP + 子网掩码，求：地址类别、网络地址、直接广播地址、受限广播地址、主机号、可用 IP 范围。

固定解题流程（先把 IP 和掩码全部转成二进制）：

求什么方法
地址类别看第一字节：1–126 为 A，128–191 为 B，192–223 为 C
网络地址网络位不变，主机位全置 0（与掩码做与运算）
直接广播地址网络位不变，主机位全置 1
受限广播地址永远是 255.255.255.255（32 位全 1）
主机号网络位全置 0，主机位保留
可用主机数2主机位数 − 2
第一个可用 IP网络地址 + 1

实战示例（2023 年 3 月真题）：IP 111.181.21.9，掩码 255.192.0.0

  • 掩码二进制 11111111.11000000... → 前 10 位网络位 → A 类
  • 网络地址：主机位清 0 → 111.128.0.0
  • 直接广播地址：主机位全 1 → 111.191.255.255
警惕反推题：给广播地址/最后可用 IP 反求 IP 或网络号，原理一样，只是倒着做——平时务必练熟逆向推导。

第 2 题：路由器/交换机配置命令填空（约 10 分）

给出一段完整配置，挖空让你填。纯背命令，没有理解难度。高频填空词：

enable                    ← 进入特权模式
configure terminal        ← 进入全局配置模式
ip route 0.0.0.0 0.0.0.0  ← 缺省路由
network + 通配符掩码       ← OSPF 宣告
permit / deny             ← ACL 动作
standard / extended       ← 标准/扩展 ACL
any                       ← 匹配所有地址
vty 0 4                   ← 虚拟终端线路
bandwidth                 ← 设置接口带宽
switchport access vlan    ← 端口划入 VLAN
no shutdown               ← 激活接口

技巧：把配置命令打印成一页纸（刷题库右上角「打印考场命令纸」），候考区反复默写。

第 3 题：DHCP 报文分析（约 10 分）

考四步交互顺序和方向，记住 DORA：

  1. Discover（客户机 → 服务器，广播 255.255.255.255）
  2. Offer（服务器 → 客户机，提供 IP）
  3. Request（客户机 → 服务器，仍是广播）
  4. ACK（服务器 → 客户机，确认）

常见空：报文名称、传输方向、目的 IP（Discover/Request 为广播地址）、客户端 MAC、租约时间。

第 4 题：Sniffer / Wireshark 抓包分析（约 10 分，最难但套路深）

给抓包截图，先看 Protocol 列判断协议，再对应套路：

  • DNS：看解析的域名、DNS 服务器 IP（第 5–8 行通常是域名解析）
  • ICMP：出现 TTL 逐条递减 → 说明执行的是 tracert 命令；Echo 报文 → ping
  • TCP：三次握手 SYN → SYN,ACK → ACK；FTP 用 20/21 端口
  • HTTP：看 GET / POST 请求行

经典考点——求主机网络号最长位数：取抓包中本机 IP 与第一条路由 IP，转二进制后找相同前缀的位数。例：202.113.64.137 与 202.113.64.129，前三段相同（24 位），第四段 10000101 与 10000001 前 4 位相同 → 网络号最多 28 位。

经典考点——判断执行的命令：有 DNS 解析域名 + 后续 TTL 递减 → tracert 域名；只有 Echo 对 → ping。

应用题（20 分）：路由聚合与子网划分

  • 地址聚合：各网段转二进制找相同前缀，聚合块必须按块大小边界对齐（129/130 不能直接聚合成 /23，需拉齐到 128–131）
  • 常见提问：汇聚后的超网地址、可用地址数、防火墙/IDS 部署位置、监听路由器流量用什么设备（答 TAP 分路器）

6考场实战技巧

  1. 先做选择题、尽快做完：理论选择题不确定的多，不要恋战，给综合题和应用题留足时间——大题规律性强、更容易拿分。
  2. 选择题「找不同」：实在不会的题，选一个「最不像同类」的选项，正确率不低。但能理解尽量理解。
  3. 计算题找规律：大题「每次就那几个数」，多刷之后甚至不用重新计算，看数就能出答案。
  4. 填空注意空格：电子答题时不要多打空格导致判错——用电子题库软件练习就是为了避开这个坑。
  5. 考前一天：不学新知识，只过操作题 + 配置命令纸；本校考试提前踩点，外校考点提前订安静的住处。
  6. 候考区：把配置命令纸拿出来最后过一遍，纯记忆题趁热打铁。

7高频易混点速查（错题重灾区）

易混点区分
RIP vs OSPF vs BGPRIP：距离向量，UDP 520，跳数≤15；OSPF：链路状态，Dijkstra，直接封装 IP（协议号 89）；BGP：路径向量，TCP 179，AS 之间
ADSL vs HFCADSL 电话线非对称（下行 8M 上行 1M）；HFC 有线电视同轴电缆 + Cable Modem，共享介质
冲突域 vs 广播域交换机隔离冲突域（每端口一个），VLAN/路由器才隔离广播域
标准 ACL vs 扩展 ACL标准 1–99 只查源地址，靠近目的端应用；扩展 100–199 查源/目的/协议/端口，靠近源端应用
802.11b/a/g/nb：2.4G/11M；a：5G/54M；g：2.4G/54M 兼容 b；n：MIMO 最高 600M
IDS vs IPSIDS 只监测告警；IPS 在线可主动阻断
ping vs tracertping 用 ICMP Echo；tracert 利用 TTL 递减 + ICMP 超时报文
IPv6 表示128 位，8 组十六进制，:: 压缩只能用一次
