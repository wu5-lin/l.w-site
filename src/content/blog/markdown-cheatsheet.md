这是写文章时可以翻的一页。正文用 Markdown。编辑器里可以切到预览，看过再保存。

## 标题

一行开头的 `#` 越多，标题越小。文章标题本身已经在页面最上面，正文里从两级开始就够。

写法：

```markdown
## 二级标题

### 三级标题
```

效果：这一节的标题就是二级标题。下面是三级标题。

### 三级标题

## 粗体和斜体

写法：

```markdown
这是 **粗体**，这是 *斜体*，这是 ***又粗又斜***。
```

效果：

这是 **粗体**，这是 *斜体*，这是 ***又粗又斜***。

## 列表

写法：

```markdown
- 第一件
- 第二件

1. 先做这个
2. 再做那个
```

效果：

- 第一件
- 第二件

1. 先做这个
2. 再做那个

## 链接

方括号里是给人看的字，圆括号里是地址。站内页面用 `/` 开头。

写法：

```markdown
回到 [首页](/)。
```

效果：

回到 [首页](/)。

## 图片

在 Pages CMS 的正文里点插图，文件会存进仓库的 `public/images/`。引用时不要写 `public`，地址以 `/images/` 开头：

```markdown
![像素小狗](/images/sun.webp)
```

`sun.webp` 只是举例。换成你上传后的文件名即可。站点头像已经在网站上，写法一样：

```markdown
![像素画：小狗抱着太阳](/avatar.webp)
```

效果：

![像素画：小狗抱着太阳](/avatar.webp)

## 引用

写法：

```markdown
> 还没写完的句子，可以先放在引用里。
```

效果：

> 还没写完的句子，可以先放在引用里。

## 行内代码和代码块

短的用一对反引号，包在句子里。

写法：

```markdown
勾选 `draft` 就是草稿。
```

效果：

勾选 `draft` 就是草稿。

整段代码用三道反引号围起来，第一道后面可以写语言名。写法：

````markdown
```text
npm run dev
```
````

效果：

```text
npm run dev
```

## 分隔线

写法：

```markdown

```

效果：

---

## 表格

写法：

```markdown
| 标签 | 什么时候用 |
| --- | --- |
| 新手编程 | 搭网站、记语法 |
| 随笔 | 没有特定题目的时候 |
```

效果：

| 标签 | 什么时候用 |
| --- | --- |
| 新手编程 | 搭网站、记语法 |
| 随笔 | 没有特定题目的时候 |

## 三个小提示

段落之间要空一行。不空行的两句会粘成一段。

写法：

```markdown
这是第一段。

这是第二段，中间空了一行。
```

效果：

这是第一段。

这是第二段，中间空了一行。

保存之前，在编辑器里切到预览看一遍。预览用的就是这套 Markdown。

还没写完就勾上「草稿」。勾着的时候，首页、标签页、RSS 和正式构建都不会出现这篇。改好后取消勾选，再保存，才会公开。
