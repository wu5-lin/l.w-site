Capabilities

核心能力

把你每天在网分上测的数据直接变成论文里的 εr 与 Q×f。

Σ

精确解（Kobayashi–Katoh）

数值求解 TE₀₁δ 模特征方程 J₀(u)/(u·J₁(u)) = K₀(w)/(w·K₁(w))，把样品外的倏逝场算进去，结果作为主值。

◎

磁壁参考（Hakki–Coleman）

提供常用磁壁近似作对照。注意它在 D/L≈2 的典型几何下会系统性偏高约 14%，页面已明确标注区分。

ƒ

Q×f 与 tanδ 直出

由无载品质因数 Q₀ 与谐振频率 f₀ 直接算出 Q×f，并按 tanδ ≈ 1/Q₀ 给出损耗角正切。

🛡

纯前端本地计算

全部公式在手机本地运行，数据不上传，无云函数、免运维，结果可复现、可审计。

Workflow

工作流程

从样品尺寸与网分读数到 εr、Q×f，四步完成。

输入样品尺寸

填入圆柱样品的直径 D 与厚度 L（每个块体一组）。

输入网分读数

填入谐振频率 f₀（GHz）与无载品质因数 Q₀。

精确求解 εr

解 TE₀₁δ 特征方程，输出精确解，磁壁近似作参考。

输出 Q×f 与 tanδ

直接得到论文要的 Q×f 与损耗角正切，可一键复制。

Architecture

技术要点

Δ

特征方程数值解

Bessel J₀/J₁/K₀/K₁ + 二分求根，精确解可回代验证。

≠

精确解 vs 磁壁近似

磁壁近似在 D/L≈2 时偏高约 14%，论文数据须用精确解。

⚙

超截止预警

内置 f₀ < c/(2L) 适用前提校验，超限自动提示。
