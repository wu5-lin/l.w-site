工作原理

  1. 标尺校准：先在图中标出已知长度，把像素换算成真实尺寸（nm/µm/mm），后续所有直径按真实单位输出。
  2. 晶粒模式（致密烧结组织）：晶粒互相紧贴、整幅图没有背景时，灰度阈值从原理上切不开。改为用形态学梯度找出晶界（高梯度线）→ 闭运算连接断续晶界 → 剩下的区域就是晶粒 → 连通域作种子 → 分水岭把晶界像素按中线平分给相邻晶粒。最后一步保证面积守恒：若把晶界像素直接丢掉，测得的直径会系统性偏小约 17%。该模式只看"边缘"而不看"亮暗"，因此晶界偏亮或偏暗都能处理。
  3. 阈值模式（分散粉末）：灰度化 → 自适应/Otsu/手动阈值分离颗粒 → 开闭运算去噪 → 按面积、圆度、边界过滤碎片。
  4. 分水岭分离（阈值模式可选）：以距离变换的局部极大为种子切开相互接触的颗粒。种子逐点判定、与整体尺度无关，所以同一张图里大颗粒和小颗粒都能被正确分开（旧的全局阈值做法会吞掉小颗粒，实测欠分割 41%）。
  5. 粒径换算：等效圆直径 D=√(4A/π)，另给最小/最大 Feret 直径（凸包最远点距与最小宽度）——晶粒多为多边形，Feret 比等效圆直径更能反映真实尺寸。
  6. 统计输出：D10/D50/D90、不均匀度 Cu、曲率 Cc 与分布直方图；明细另含圆度与实心度（面积/凸包面积，明显偏低说明该颗粒可能是未分开的粘连体）。

本工具在浏览器本地运行 OpenCV (wasm)，图像不会上传到任何服务器，适合处理敏感科研数据。算法为传统计算机视觉 + 轻量智能分割，日常测量足够；如需更高精度可后续接入 YOLO/SAM 深度学习模型。

常见问题

页面打开后一直显示"加载 OpenCV"？

OpenCV.js 约 13MB（wasm 已内联），首次加载需几秒，请耐心等待；若长时间不动，可强制刷新（Ctrl+F5）清除缓存后重试。

结果颗粒数偏多/偏少？

晶粒模式：先调「晶界灵敏度」，调高会切出更多晶粒（晶界判定更严），调低则反之；再调「最小晶粒面积」滤掉碎片。阈值模式：调整「最小面积」「最小圆度」，或切换「颗粒亮/暗」；对比度低时改用「手动阈值」微调。

怎么判断该用晶粒模式还是阈值模式？

看整幅图有没有"背景"：晶粒互相紧贴、看不到空隙（烧结致密陶瓷的表面/断口）→ 晶粒模式；能看到颗粒之间的背景（分散粉末、悬浮液）→ 阈值模式。判断错了会有很明显的征兆：致密组织用阈值模式会切出大量碎片、圆度被迫降到很低；分散粉末用晶粒模式则几乎只能切出孤立的小块。

直径单位怎么选？

推荐流程：先完成标尺校准，再做分割调节与正式分析。用"标尺校准"：量出图中已知长度对应的像素数并填入实际长度与单位（nm/µm/mm）。不填则按像素显示。修改标定值后，已出的统计结果与直方图会即时按新单位重算，无需重新分析。

轮廓为什么是五颜六色的？能否改？

在"轮廓着色"里可切换：按粒径梯度（青→紫，一眼看出大小分布，默认）或 多色区分（每颗颗粒一个独立颜色，便于核对单颗）。两者都不影响统计数值。

什么是"分水岭分离"？

颗粒常相互接触、被误判成一整块。开启后，工具对距离变换图取局部极大作为每颗粒的种子，再用分水岭把接触处切开分别测量，颗粒数与粒径分布更准确。旧的"全局阈值取种子"做法在大小颗粒共存时会吞掉小颗粒（实测欠分割约 41%），现已改为逐点自适应的局部极大。细长或严重堆叠的颗粒仍可能被切分，此时可关闭该选项。

为什么要看"实心度"？

实心度 = 轮廓面积 ÷ 其凸包面积，衡量形状的凹陷程度。单个晶粒近似凸多边形（约 0.97），若某条记录明显偏低（如 <0.9），说明这个轮廓凹陷严重、很可能是两个未切开的晶粒连在一起，值得回图核对。这一列可作为分割质量的自检依据。
